Install

Five minutes.
Then just work.

  1. Download and run the installer

    Download Engram and run it. The Engram icon appears in the system tray and starts with Windows from then on.

  2. Open Setup

    Click the tray icon and the Engram window opens. Choose Setup at the top.

  3. Pick where your memories live

    Choose a folder, for example C:\ENGRAM, and click Use this folder. This installs Claude's instruction and puts the engram command on the path.

  4. Let Claude run engram

    Click Let Claude run engram. Claude can then read and add to its memory without asking each time. It can't delete or edit a memory, and it can't run anything else.

  5. Sync the brain Optional

    Create an empty private GitHub repository, paste its address under Sync the brain and click Sync to this repository.

  6. Restart Claude once

    Close and reopen Claude Code, then start a new session. From here on, Claude remembers.
