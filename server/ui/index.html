The one sentence

Engram is the memory an AI keeps for one person. Every session starts by remembering, works by recording, and ends by closing, in a folder on this computer that you own.

The three words

Engram is the application, the command, the act of writing one memory, and the memory itself. Cortex is the map of Context Containers: a folder tree with a map at the top of each folder. Echo is the short extract at the top of every engram; to read memory is to read Echos. Everything else is plain English.

What is stored

One note per engram. At the top, the Echo: what was asked, what is now true, what to watch for. Below it, the engram: your words verbatim, what was done, the decision if there was one, the files produced and where they live. Links between engrams are typed: cites, supersedes, refines, confirms, contradicts, produced from, consolidates. Files never enter the memory; only the record of them does.

How it is organised

The Cortex is a folder tree. A folder is a region of knowledge, as deep as the subject needs. At the top of every folder is a map, rebuilt by the tool from the engrams beneath it: a digest, the rulings in force, the strongest links out, the children, the known gaps. The maps are the table of contents.

How the AI reads it

A session wakes on the root map, takes the brief of the project it is working on, then recalls on its task: every Echo scored, the regions the task names weighted, links followed one hop, the decisions in force first, cut at a token budget. It reports the route it took and what it spent. A second session on the same project picks up in one read.

How you read it

Search works like a web search. Type a project name and you get its regions, its rulings in force and every memory under it. Type a topic and you get every Echo that speaks of it, best first. Live shows every memory arriving as sessions work, and you can add or edit a memory yourself.

How it stays honest

To the AI an engram is immutable: a wrong one is answered by a new one that links it, and a decision that replaces another says so. Two rulings that cannot both stand are flagged for you; the tool never picks. Only you edit a memory, from this page, and the note keeps the date it was edited.
